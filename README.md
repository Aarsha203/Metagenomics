Post-Binning Analysis Pipeline for Whole Genome Sequencing

This repository provides a comprehensive pipeline for downstream analyses after metagenomic binning of Whole Genome Sequencing (WGS) data. The workflow includes:

    Functional Annotation – Automated annotation of metagenome-assembled genomes (MAGs) using:

        KEGG (Kyoto Encyclopedia of Genes and Genomes)

        GO (Gene Ontology)

        COG (Clusters of Orthologous Groups)

    Biomarker Identification – Detection of key genomic features using specialized tools for:

        Antibiotic Resistance Genes

        Plant Growth-Promoting Genes (PGPg)

        And other relevant biomarkers

The pipeline is designed for efficiency and reproducibility, enabling researchers to extract biological insights from binned metagenomic data seamlessly.
